# 診療放射線技師ニュース

診療放射線技師向けのニュース、学会・研修日程、香川県技師会の案内、医薬品供給状況をまとめる静的サイトです。

## 2026年11月7日の移行準備

Macの原本（2026年11月6日、コミット `588bfbb`）からニュースに必要なファイルを複製しました。
旧リポジトリに同居する beer-save / ion-chemistry は公開候補に含めていません。原本と全Git履歴は別のローカルバックアップに保全されています。この公開候補には旧Git履歴を含めていません。

公開予定: https://hijikiogan-sudo.github.io/radiology-technologist-news/

## ローカル表示

このフォルダで `python3 -m http.server 8000 --bind 127.0.0.1` を実行し、ブラウザで http://127.0.0.1:8000/ を開きます。
HTMLを直接開くとJSON取得ができないため、簡易サーバーを使います。

## 開発

まず AGENTS.md を読みます。収集処理は scripts/update_news.py、画面は index.html、配信キャッシュは sw.js です。
Pythonとpytestを用意し、`python3 -m pytest -q -p no:cacheprovider tests` で検証します。実収集で供給情報を更新するときは openpyxl が必要です。
ニュース収集スクリプトは既存JSONを更新し、保存期限を超えた記事を削除するため、動作確認では複製上で実行します。

## ブラウザ設定

あとで読む、担当分野などは旧URLを開いたブラウザ側にあります。公開先URLが変わると自動で移りません。アプリの設定の「端末間の受け渡し」で対応する項目を移します。既読状態や表示テーマなどは移行対象に含まれない項目があります。
